# Week 04 — Laravel Fundamentals

## Overview

Week 04 marks the beginning of my learning journey with the Laravel PHP framework. After working with PHP, MySQL, and CRUD-based applications, I started exploring Laravel's structure and the concepts used to organize modern web applications.

## Topics Explored

* Introduction to Laravel
* Laravel project structure
* MVC (Model–View–Controller) architecture
* Routes and request handling
* Controllers and application logic
* Blade templating basics
* Laravel Artisan command-line interface

## Learning Outcomes

* Understood the purpose of using a PHP framework.
* Explored how Laravel organizes application files.
* Learned the basic relationship between routes, controllers, and views.
* Began understanding how MVC separates application responsibilities.
* Explored Blade as Laravel's templating engine.
* Became familiar with common Artisan commands.
