# Week 14 – Angular Basics

## Overview

Week 14 marks the beginning of the Angular learning phase of my Full Stack Development Internship.

This week focuses on understanding the fundamentals of Angular and TypeScript, which are essential for building dynamic and structured frontend applications.

## Learning Objectives

* Understand what Angular is and its role in frontend development.
* Get familiar with TypeScript fundamentals.
* Understand the structure of an Angular application.
* Learn about Angular components.
* Understand templates and how they display application content.
* Explore data binding in Angular.

## Topics Covered

### 1. Introduction to Angular

* Understanding Angular and its purpose.
* Overview of Angular as a frontend framework.
* Understanding the role of Angular in web application development.

### 2. TypeScript Fundamentals

* Introduction to TypeScript.
* Understanding variables and data types.
* Basic TypeScript syntax.
* Understanding type annotations.

### 3. Angular Components

* Understanding component-based architecture.
* Introduction to Angular components.
* Understanding component structure.
* Exploring component templates and logic.

### 4. Angular Templates

* Understanding Angular templates.
* Displaying content through templates.
* Connecting component data with the template.

### 5. Data Binding

* Understanding the concept of data binding.
* Exploring interpolation.
* Understanding property binding.
* Understanding event binding.
* Introduction to two-way data binding.

## Key Learning Outcomes

* Gained an introduction to Angular and its frontend development approach.
* Understood the importance of TypeScript in Angular applications.
* Learned the basic structure and purpose of Angular components.
* Explored how templates display component data.
* Developed an initial understanding of data binding.

## Technologies & Tools

* Angular
* TypeScript
* HTML
* CSS
* Visual Studio Code

## Weekly Summary

Week 14 introduced the fundamentals of Angular and TypeScript. The learning focused on components, templates, and data binding, establishing the foundation for developing dynamic frontend applications.
