# Week 14 – Introduction to Angular & Fundamentals

## Overview

Week 14 marks the beginning of the Angular learning phase of my Full Stack Development Internship.

This week focuses on getting familiar with Angular, setting up the development environment, and understanding the fundamental concepts required to build frontend applications using Angular and TypeScript.

The learning journey begins with installing the necessary tools, creating and running an Angular application, and exploring its basic project structure. It also introduces the core concepts of Angular, including components, templates, and data binding.

## Learning Objectives

* Understand Angular and its role in frontend development.
* Set up the Angular development environment.
* Learn the basics of TypeScript.
* Understand Angular application structure.
* Explore Angular components and templates.
* Understand different types of data binding.
* Create and run a basic Angular application.

## Topics Covered

### 1. Introduction to Angular

* Understanding Angular and its purpose.
* Overview of Angular as a frontend framework.
* Understanding the role of Angular in modern web development.
* Introduction to component-based architecture.

### 2. Development Environment Setup

* Install Node.js (LTS version).
* Understand npm (Node Package Manager).
* Install Angular CLI.
* Create a new Angular project.
* Run the application using `ng serve`.
* Understand the basic Angular project structure.

### 3. TypeScript Fundamentals

* Introduction to TypeScript.
* Understanding variables and data types.
* Basic TypeScript syntax.
* Understanding type annotations.
* Introduction to functions and classes.

### 4. Angular Components

* Understanding Angular components.
* Exploring component structure.
* Understanding component logic and templates.
* Creating and using components.

### 5. Angular Templates

* Understanding Angular templates.
* Displaying data through templates.
* Connecting component properties with the template.
* Understanding template expressions.

### 6. Data Binding

* Understanding the concept of data binding.
* Interpolation.
* Property binding.
* Event binding.
* Two-way data binding.

## Commands Practised

```bash
# Check Node.js version
node -v

# Check npm version
npm -v

# Install Angular CLI
npm install -g @angular/cli

# Check Angular CLI version
ng version

# Create a new Angular project
ng new my-angular-app

# Navigate to the project directory
cd my-angular-app

# Run the development server
ng serve
```
