# Task 15 — Laravel Profile Page

## Overview

This project documents my implementation of a Profile Page using the Laravel PHP framework. It is part of Weeks 05–06 of my Full Stack Development Internship.

The task focuses on applying Laravel fundamentals, including routing, controllers, and Blade templating, to organize a profile page.

## Objectives

* Practise Laravel routing and request handling.
* Understand how controllers manage application logic.
* Use Blade templates to create a profile interface.
* Organize Laravel code into separate files.
* Strengthen my understanding of Laravel's MVC architecture.
