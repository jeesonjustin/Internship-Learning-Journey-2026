# Weeks 05–06 — Laravel Development

# Task 15 – Laravel Profile Page

## Project Overview

This task focuses on understanding the fundamentals of Laravel by developing a simple Profile Page using the MVC (Model-View-Controller) architecture.

The application demonstrates how routes, controllers, and Blade templates work together to display user information dynamically.

## Objectives

* Understand the Laravel MVC architecture.
* Learn how Laravel routes work.
* Create and use controllers.
* Pass data from a controller to a Blade view.
* Display profile information using Blade templates.
* Understand the Laravel request-response flow.

## Features

* Dynamic user profile display.
* Personal information presentation.
* Controller-based data handling.
* Blade template rendering.
* Simple and organized profile interface.

## Technologies Used

* PHP
* Laravel
* Blade Templates
* HTML
* CSS

## Implementation

### 1. Routing

Defined a route in `web.php` to handle requests for the profile page.

### 2. Controller

Created `ProfileController.php` to prepare user profile information and pass it to the Blade template.

### 3. Blade View

Created `profile.blade.php` to display the profile information in a structured layout.
