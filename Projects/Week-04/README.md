# Week 04 — Laravel Fundamentals

## Overview

This section documents my introduction to Laravel during Week 04 of my Full Stack Development Internship.

The focus is on understanding Laravel's application structure and the core concepts needed before developing more advanced Laravel applications.

## Topics

* Laravel framework introduction
* Project structure
* MVC architecture
* Routing
* Controllers
* Blade templating
* Artisan CLI

## Practice Areas

| Topic             | Purpose                                                |
| ----------------- | ------------------------------------------------------ |
| Project Structure | Understand the organization of a Laravel application   |
| Routing           | Learn how application URLs are mapped to actions       |
| Controllers       | Explore how application logic is organized             |
| Blade Views       | Understand how dynamic pages are rendered              |
| MVC               | Learn how models, views, and controllers work together |
| Artisan           | Become familiar with Laravel command-line tools        |
